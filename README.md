College Attendance System

A web-based College Attendance Management System built using Flask (Python), HTML, CSS, JavaScript, and SQLite.

This system helps faculty efficiently manage student attendance for different branches, years, semesters, and sections.

🚀 Features

✅ Faculty Login with class selection (Branch, Year, Semester, Section)

✅ Automatically loads  students per selected class

✅ Mark attendance as Present or Absent

✅ “Mark All Present” and “Mark All Absent” options

✅ Save attendance (cannot modify after saving for the day)

✅ View Present and Absent students in popup modals

✅ Monthly Attendance Percentage (based on classes per month)

✅ Clean and responsive dashboard UI

🛠️ Technologies Used

Backend: Python (Flask)

Frontend: HTML, CSS, JavaScript

Database: SQLite
